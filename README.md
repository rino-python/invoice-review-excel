# 請求書の転記チェック

届いた請求書から日付・金額・取引先を抜き、税計算と必須項目を検算して、怪しい行だけ「要確認」にした Excel を返します。手打ち転記の前に、数字の食い違いを機械で拾う想定です。

> [!note]
> クラウドソーシング向けポートフォリオの3本目です。デモの受取側は架空の「合同会社 灯台デザイン」。実在の請求書や個人情報は使いません。生成AIは必須ではなく、鍵があるときだけ抜けた項目の補完に使います。

## デモ

- ローカル起動：下記「起動方法」
- 操作の流れ：`操作マニュアル.md`
- サンプル：[`samples/請求書サンプル.zip`](samples/請求書サンプル.zip)

## できること

- 文字のある請求書（`.txt` / `.md` / `.pdf`）から、請求番号・請求元・発行日・支払期限・税額を抜く
- 税抜＋消費税と税込が合うか検算する
- 必須項目の欠落、支払期限が発行日より前、請求番号の重複を「要確認」にする
- 要確認でも一覧には残し、理由を付ける（黙って捨てない）
- 任意で OpenAI API キーを渡し、規則で抜けた項目だけ補完する（埋まっている値は上書きしない。補完した行は要確認）

## できないこと

- スキャン画像の OCR（文字の無い PDF）
- 会計ソフトへの自動登録、振込の実行
- 問い合わせメールの分類
- 生成AIのチャット画面
- API キーをリポジトリや結果 Excel に保存すること

案件では、御社の請求書レイアウトに合わせて抜き方を足します。スキャン画像が主なら、OCR は別見積もりです。

## 画面の使い方

左の検収パネルに請求書を上げるか、「同梱サンプルで試す」にチェックして、「読み取って検算する」を押します。件数と生成AIの呼び出し回数を確認してから実行します。結果は要確認タブを先に出します。

1. （任意）サンプル一式をダウンロードして中身を見る
2. 請求書を上げる、または同梱サンプルにチェックする（一度に20件まで）
3. 確認画面のあと、要確認・転記一覧を見て結果 Excel を保存する

結果ブックのシート：

| シート | 内容 |
|---|---|
| 転記一覧 | 抜いた項目。転記可は緑、要確認は赤 |
| 要確認 | 怪しい行と理由 |
| 判定基準 | 検算のルール |
| 処理メモ | 件数、生成AIを呼んだか、項目を埋めたか、鍵の扱い |

## 技術スタック

- Python 3.11+
- Streamlit（画面）
- pypdf（文字のある PDF）
- pandas / openpyxl（表と Excel）
- 生成AIは任意（OpenAI API。SDK は使わず、鍵は環境変数か画面のみ）

## 起動方法

`README.md` があるフォルダでターミナルを開いてください。ホームフォルダ（`C:\Users\名前`）で打つと、ファイルが見つからずエラーになります。

エクスプローラーでこのフォルダを開き、アドレスバーに `powershell` と入力して Enter すると、正しい場所で開けます。

Windows の PowerShell で `.venv\Scripts\activate` がセキュリティエラーになるときは、先に1回だけ次を実行します。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

そのあと：

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python generate_sample.py
streamlit run app.py
```

ターミナルに `Email:` と出たら、何も入力せず Enter を押してください。初回だけ聞かれます。聞かれたままブラウザを開くと、つながりません。

ブラウザで `http://localhost:8501` が開きます。

生成AIを試すときだけ、環境変数 `OPENAI_API_KEY` を置くか、画面の欄に貼ってください。鍵があるとき、抜けた項目の原文を OpenAI へ送ります。`.env` は git に入れません。

## 工夫した点

- デモは API キーなしで動く。見せる核は検算と要確認
- 生成AIは抜けた項目の補完だけ。金額の上書きはしない。補完した行は要確認
- 税計算・日付の前後・番号重複はプログラムで見る
- 一度に20件まで。実行前に件数と生成AIの呼び出し回数を出す。同じファイルの再実行では API を呼ばない
- 1本目（紺の集計）・2本目（ティールの監視）と色と操作を変えている

## カスタマイズ例（案件）

- 御社フォーマットの項目名に合わせる
- インボイス登録番号の形式チェック
- 文字のある PDF が主なら、そのレイアウト専用の抜き方
- スキャン画像が主なら OCR（Tesseract または Vision API）を別途追加
